# Atelier 0.8 — Your first idea, four pages further

A more focused studio homepage and three ready-to-edit starter kits. Build a coherent series instead of starting with a blank canvas.

## What is new

- **Creator Carousel:** hook, story, useful takeaway and closing page.
- **Product Story:** introduction, problem, solution and next step.
- **Study Notes:** learning goal, explanation, example and self-check.
- Each kit opens as its own project with four editable pages. Your existing projects are preserved.
- A redesigned homepage, consistent Atelier branding and real product screenshots.
- Download instructions, contribution guides and issue forms.

## Download and run

Download **Atelier-v0.8.0.zip**, extract it and open **docs/START-HERE.md**.

**Requires Node.js 20.12+ and a current desktop browser.** On Windows, double-click `START-WINDOWS.cmd`. On macOS/Linux, run `npm start` in the extracted folder. Then open http://127.0.0.1:4173.

The archive is a portable source package, not a native installer. It includes the static editor and optional account-server sources. The static editor needs no dependency install, signup or API key. Real email and Google sign-in require your own provider configuration.

## Validation

96 Node tests, 17 browser checks, JavaScript syntax checks and static build passed locally. Starter-kit creation and page switching were checked in the running application.

## Current limits

The interface is in German; desktop browsers are the main target. This early release does not provide full Canva parity, AI generation or a complete video editor. Projects in the static mode are stored in the current browser; export backups before clearing browser storage. Details are in README.md and docs/FEATURES.md.

Feedback is welcome through the repository's bug report and feature request forms. Please remove private designs and credentials before attaching files.
