# Share Atelier

Ready-to-adapt launch copy and a practical checklist. These are drafts, not published posts. There is no guarantee of reach, stars or virality.

## Before a public launch

- Make the repository public only after reviewing all files and commit history for secrets and personal content. A private repository cannot be discovered or cloned by the general public.
- Test the quickstart on a fresh machine or checkout. Offer a demo URL only once it is deployed and verified.
- Record a short real workflow: open a template, edit the headline, change colors, export a PNG. Show the final design first.
- Use a design you own. Remove account details, email addresses and private projects from recordings.
- Explain the current scope: early-stage, German interface, desktop focus, optional self-hosted accounts. Do not claim Canva feature parity or AI tools that do not exist.
- Include one destination link and one clear request for feedback. Respect community rules and avoid repeated unsolicited promotion.

## English draft

> I’m building Atelier: an open-source design editor for social posts, posters and presentations. The static editor runs locally, needs no account and exports without watermarks. It includes editable templates, layers, charts and multipage designs. It’s an early release with a German interface, and I’d love feedback on the editing workflow. Code and setup: https://github.com/m4z8p6fy9m-coder/atelier-design-studio

## A 20-second demo

| Time | Show |
| --- | --- |
| 0–3 s | The finished poster and the words “Made in Atelier” |
| 3–8 s | Open the template and replace its headline |
| 8–13 s | Change its colors and align an element |
| 13–17 s | Export the actual design as PNG |
| 17–20 s | Show the result and the repository address |

Use the real app recording rather than presenting a concept image as working software. Start with a small relevant audience, answer questions and turn repeated feedback into focused issues.
